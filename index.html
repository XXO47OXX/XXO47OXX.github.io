🌟 Featured: spa-reader-mcp

MCP server for rendering JavaScript SPAs to LLM-ready Markdown

Traditional web scrapers fail on Single Page Applications. spa-reader-mcp launches a headless Chromium browser, waits for full rendering, and extracts clean Markdown — ready for LLM consumption.

🎯 SPA Rendering

Headless browser via Playwright handles complex JavaScript-driven layouts

🧹 Clean Output

Extracts article content with optional YAML frontmatter for LLM processing

⚡ Efficient

Singleton Chromium instance reuses across requests for low-overhead rendering

🔒 Secure

SSRF protection and selector injection prevention for untrusted URLs
